Project Documentation — System Architecture Overview

This document describes the high-level architecture of the data processing pipeline.

## Components

1. Data Ingestion Layer: responsible for collecting raw events from upstream sources
2. Processing Engine: applies transformation rules and business logic
3. Storage Backend: persists processed records to the data warehouse

## Configuration

Standard configuration is stored in config.yaml at the project root. Environment-specific
overrides are loaded from .env files in each deployment environment.
